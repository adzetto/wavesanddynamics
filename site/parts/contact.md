# contact: the Contact page (contact.html)
`render(info)` returns the whole page body, `<div class="wrap contact">` with its `<h1>` (build.py's `wrap_page()` passes it through). `info` = dict(email, personal, department, institute, city, country, links, cv_href); a missing key takes its default, `links` is cv.json's `[{"label","href","kind"}]` (known kinds sorted scholar, linkedin, researchgate, github, youtube; the service's own name is shown; non-http links and this site are dropped). `email` and `personal` must each be one of `PUBLIC_EMAILS` (korkutkaynardag@iyte.edu.tr, korkut.kaynardag@gmail.com; mirrored from build.py, a test holds them equal); any other is refused for its default with a `!!` line, and the same address given twice is shown once.
