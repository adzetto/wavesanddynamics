latinmodern-math-deck.woff2: Latin Modern Math (B. Jackowski, P. Strzelczyk,
P. Pianowski, for the TeX user groups), subset with fontTools to the operators,
arrows, Greek and letterlike symbols the slides use, for the glyphs CMU Serif
does not carry (an integral, proportional to, less or equal, a sum ...).
Source: MiKTeX, fonts/opentype/public/lm-math/latinmodern-math.otf.
License: GUST Font License, GUST-FONT-LICENSE.txt beside this file.
Used only to render the slides (tools/deck/render.py). The font file is not
published; the glyphs the slides use travel inside the deck's PDF (an embedded
subset) and its SVGs (as outlines), as the license allows for documents.
