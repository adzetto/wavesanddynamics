Bayesian strength example: the actual calculation

Same strength data: n = 25, x̄ = 32 MPa, known σ = 3 MPa. Prior mean 30 MPa and prior SD 2 MPa.

Prior variance v₀ = 2² = 4 MPa²

Data variance vᴅ = 3²/25 = 0.36 MPa²

vₚ = 1/(1/4 + 1/0.36) = 0.3303 MPa²

Posterior SD = √vₚ = 0.575 MPa

mₚ = (30/4 + 32/0.36)/(1/4 + 1/0.36)

mₚ = 0.0826 × 30 + 0.9174 × 32

mₚ = 31.83 MPa

About 8% prior weight and 92% data weight.

95% credible interval

31.835 ± 1.96(0.575) = [30.71, 32.96] MPa

95% posterior probability, given this model, prior and data.

The more precise source receives more weight. More tests increase the data’s weight.
