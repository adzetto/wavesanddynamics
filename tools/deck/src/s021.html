Hypothesis test: is an assumed value still plausible?

Same 25 tests: x̄ = 32 MPa, σ = 3 MPa. The supplier claims μ = 33 MPa. Would data like ours be unusual if the claim were true?

Four steps

1 Claim: H₀: μ = 33 MPa; H₁: μ ≠ 33 MPa

2 Test statistic: z = (32 − 33)/0.6 = −1.67

3 p-value: P(|Z| ≥ 1.67) = 9.6%

4 At α = 5%: 9.6% > 5%, do not reject H₀

Read it carefully

Consistent with slide 17: the 95% CI [30.82, 33.18] contains 33.

Not rejecting does not prove μ = 33.

A p-value is not the probability that H₀ is true.

A test checks one assumed value; a confidence interval shows all values the data allow.
