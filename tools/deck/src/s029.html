Nonlinear f, method 1: first order (tangent line)

For a curved f, replace it by its tangent at the input means, then apply the linear formulas. If f is already linear, this is exact.

1 Approximate the function near the input means

δᵢ = Xᵢ − μᵢ cᵢ = ∂f/∂Xᵢ at X = μ Y ≈ f(μ) + Σᵢ cᵢδᵢ

δᵢ is a deviation; cᵢ is the local slope. f(μ) means evaluate f with every input set to its mean.

2 Take the expectation

Each deviation has mean zero: E[δᵢ] = 0.

Therefore μʏ = E[Y] ≈ f(μ).

3 Square the deviations and average

Var(Y) ≈ E[(Σᵢ cᵢδᵢ)²]

= Σᵢ cᵢ²σᵢ² + 2Σᵢ<ⱼ cᵢcⱼ Cov(Xᵢ, Xⱼ)

For a linear model, the tangent is the model.For a curved model, this mean can be biased.

Squared terms give the individual variances.Cross terms describe joint movement.For independent inputs, cross terms vanish.

Sensitivity coefficients appear because they are the slopes in a Taylor expansion.
