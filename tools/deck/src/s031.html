Nonlinear f, method 2: second order (add curvature)

“Order” is the highest power of the input deviation kept. First- and second-order (Taylor) approximations are the standard tools in textbooks and research papers.

One input: δ = X − μ, local slope a = f′(μ), curvature b = f″(μ)

First order: Y ≈ f(μ) + aδ Second order: Y ≈ f(μ) + aδ + ½bδ²

Why curvature matters

E[δ] = 0, but E[δ²] = σ².

So E[Y] ≈ f(μ) + ½bσ².

For a normal input, the quadratic model gives:

Var(Y) ≈ a²σ² + ½b²σ⁴.

For nonnormal inputs, skewness and thefourth central moment also enter.

X ∼ N(0, 1), Y = X²: first order predicts zero.Second order is exact: mean 1, variance 2.

A zero slope does not imply zero uncertainty when the response is curved.
