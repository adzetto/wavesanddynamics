Model outputs and decision rules are different

A single number can still contain probabilistic information. A decision needs a rule for using that information.

Model outputWhat it tells youPossible decision rule
Point prediction ŷA predicted response, often a meanCompare with an operating limit
Quantile q0.05 or q0.99A specified model tail levelUse a chosen design percentile
Exceedance probabilityChance an outcome crosses a limitRequire probability below a target
Reliability index βA scalar reliability summaryCompare with a consistent β target

Comparing β with a target is a reliability-based decision, even though β is a scalar.
