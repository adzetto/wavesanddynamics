Stationarity: do the statistical rules change with time?

Stationary means the process follows the same rules at every time: same mean, same spread, same correlation pattern. We check it by comparing statistics measured at different times.

How to read the figures

Each panel: 5 possible records of one process.Band: ±2 SD across records at each time.Left: flat band, variance 1.0 in every window.Right: band widens, variance 0.8 → 3.6.

Definition (weak stationarity)

E[X(t)] = μ

Var[X(t)] = σ²

Cov[X(t), X(t+τ)] = C(τ)

The covariance depends only on the time gap τ, not on when you look.

Statistics measured early and late agree: stationary. If not, model the change or analyze stable windows.
