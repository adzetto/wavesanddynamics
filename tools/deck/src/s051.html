Random walks: uncertainty accumulates

Each step adds an independent increment. For zero-mean increments, the expected position stays fixed while spread grows.

Useful for

Sensor bias drift, diffusion andidealized cumulative disturbances.

Mean and variance

E[Xₙ] = X₀ Var(Xₙ) = nσ²

Standard deviation grows as √n.

A random walk can have stationary increments while its level is nonstationary.
