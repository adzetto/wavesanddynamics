Markov chains (1): the rules for moving between states

A pavement section is Good, Degraded or Failed. Each year it stays or moves one state worse with fixed probabilities. The next state depends only on the current one.

1 The rules (one inspection interval)

Each year, a section stays or moves one state worse.The numbers on arrows are the transition probabilities.

2 Follow every path for two intervals, starting Good

After two years: Good 0.8 × 0.8 = 64%, Degraded 0.16 + 0.14 = 30%, Failed 0.2 × 0.3 = 6%. The three add up to 100%.

Multiply along each path; add the paths that end in the same state.
