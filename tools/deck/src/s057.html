Gaussian processes (1): a probability model for a curve

Example: cone resistance qc along a 10 m site, before any tests. We expect about 6 MPa and a smooth variation. A Gaussian process turns that belief into random curves.

Short correlation length ℓ = 0.6 m: rough

Mean m(x) = 6 MPa: best guess everywhere. Each colored curve is one possible profile (one realization).

Long correlation length ℓ = 2.5 m: smooth

Kernel k(x, x′) = σ² exp[−(x − x′)² / (2ℓ²)]: points closer than about ℓ have similar values.

Before data, a Gaussian process is a cloud of plausible curves, set by a mean and a kernel.
