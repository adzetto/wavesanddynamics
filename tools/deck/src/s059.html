Autoregression: predict using the recent past

AR(1) uses the previous value and fresh noise. The coefficient controls persistence and possible alternation.

The model

Xₜ − μ = φ(Xₜ₋₁ − μ) + εₜ

εₜ supplies fresh unpredictable input.

How it behaves

φ near 1: persistent disturbancesφ near 0: little lagged dependenceNegative φ: alternating responses

An AR(1) model is stationary when |φ| < 1 with stationary initialization.
