Estimation theory: designing rules for unknown quantities

The unknown may be a population parameter, a physical property, or a changing hidden state.

Unknown target θ

Mean μ or variance σ²Stiffness k or hidden state xₖ

Observation model

Model h(θ); noise vMeasured y = h(θ) + v

Estimator θ̂ = T(D)

A rule extracts informationfrom the observed data

What makes one rule better?

MSE(θ̂)

= E[(θ̂ − θ)²]

= variance + bias²

Bias: systematic offset. Variance: spreadMSE combines both across repeated datasets.

An estimator is a rule applied to data. An estimate is the value that rule returns for one dataset.
