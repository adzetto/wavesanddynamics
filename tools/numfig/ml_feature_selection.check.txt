Figure 6a: synthetic sensor-feature regression, seed 42, 480 independent rows.
y = 3 x1 - 2 x2 + 1.5 x3 + epsilon; epsilon SD 0.7.
x4 = 0.97 x1 + 0.15 noise; x5 and x6 independent nuisance features.
360 training rows, 120 held-out rows. Test rows never select or scale features.
Filter: top 3 absolute Pearson correlations, training rows only.
Wrapper: forward selection with 5-fold CV Ridge; scaler fitted within each fold.
Embedded: Lasso coefficient path on training-standardized inputs; alpha 0.12 fixed in advance.
Filter [1 4 2]; Wrapper [1 2 3]; Embedded [1 2 3].
Held-out RMSE with the same Ridge predictor: [1.7244020324069953, 0.6616052227324132, 0.6616052227324132].
Pearson vs standardized dot-product max error 5.55e-16.
OLS true-feature coefficients [3.024639860388903, -2.0133189015234896, 1.4831731168475346], true values [3, -2, 1.5].
Lasso path: 100 penalties from 0.001 to 10, log spaced. At 0.001 the coefficients equal the closed form w_ls - alpha (Z'Z/n)^-1 sign(w_ls) within 1.4e-08 (least squares on the standardized inputs).
Every coefficient is exactly 0 from alpha_max = max|z_j'(y - mean)|/n = 3.0380 on (closed form); below 0.98 alpha_max every penalty on the grid keeps at least one feature.
Wrapper CV RMSE by step: 2.5899, 1.6285, 0.6918, 0.6892, 0.6895, 0.6926; after three features it is flat (within 0.5%), so three are kept.
Predictive importance is not causal importance; this is a reproducible synthetic example.
