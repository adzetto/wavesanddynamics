EXPERIMENT (mlc_modelmap_exp.py): 4 features uniform on [-1, 1]; noise sd 0.3;
  simple pattern: y = x1 - 0.8 x2 + 0.6 x3 + 0.4 x4;  complex: the same + 1.2 x1 x2
  + sin(2.5 x3) cos(1.5 x4) + 0.9 sin(4 x1 + 3 x2) + 0.8 sin(6 x3 x4) + 0.6 cos(7 x1 - 5 x4).
  models (scikit-learn): ridge regression (penalty by CV), decision tree (leaf size by CV),
  k nearest neighbours (k by CV), random forest (100 trees), MLP (64, 64, early stopping).
  score: RMSE against the noiseless pattern on 4000 fresh points; repeats per size
