nf-mlc-qlearning: Figure 30, tabular Q-learning on a 5 x 5 grid world

MODEL
  5 x 5 grid, start (0, 0) bottom left, goal (4, 4) top right; actions up, down,
  left, right; a move into the wall stays put. Reward +1 on reaching the goal
  (episode ends), -0.02 for every other step (the text's own numbers).
  Q-learning, Q = 0 at first: Q(s,a) += alpha [r + gamma max Q(s',.) - Q(s,a)],
  alpha = 0.5, gamma = 0.95; epsilon-greedy with epsilon falling linearly from
  0.5 (episode 1) to 0.2 (episode 300); ties broken at random; numpy seed 21.
  300 episodes, 3803 steps; episode lengths 1..10: [12, 121, 37, 16, 25, 45, 20, 22, 14, 19];
  last 10: [16, 9, 8, 9, 10, 8, 12, 8, 10, 8] (8 is the shortest route).
  The page replays the transcript (state, action per step) with the same update in
  double precision; the replay is checked against this run below.
