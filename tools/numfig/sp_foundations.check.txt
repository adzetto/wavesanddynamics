  y(n) = w(n)^T [x(n-1) ... x(n-96)], NLMS from w = 0, mu = 0.15; y(n) is the cleaned signal.
  240 samples drawn, the filter's output sample by sample.
  CHECK 1: the filter learnt against the Wiener filter, w_o = R^-1 p from the input's exact
    autocorrelation r(k) = sum A^2/2 cos(2 pi k / P) + sigma^2 delta(k), p_j = r(j + D). Their responses at
    each tone, W(e^{iw}) = sum w_k e^{-iw(k + D)}, the NLMS filter's after n = 2000 (steady state),
    mean of 400 runs (seeds 1000 on), with standard errors:
    period 30: 1.0002 +0.0021i (+- 0.0045, 0.0045) against 0.9949 -0.0004i (+1.2 and +0.6 standard errors);
      after the 240 samples drawn, 0.9964: the filter has nearly converged.

      after the 240 samples drawn, 0.9739: the filter has nearly converged.
  CHECK 2: the single tone ALE gain (Widrow and Stearns), G = (M A^2/4) / (sigma^2 + M A^2/4), against

    period 30: |W| = 0.9949, arg W = -0.0004 rad, closed form G = 0.9949 (-4.1e-06)
    period 11.7: |W| = 0.9859, arg W = -0.0006 rad, closed form G = 0.9860 (-1.2e-04)
  CHECK 3: the error of the cleaned signal, E (y - s)^2, against theory: the Wiener residual
    J_s = sigma_s^2 - p^T R^-1 p = 0.00508 plus the NLMS excess mu/(2 - mu) (J_s + sigma^2) =

3. MACHINE LEARNING: kernel ridge regression, the points arriving one by one
  y_i = sin(2 pi x_i) + e_i, x_i uniform on [0.02, 0.98], e_i ~ N(0, 0.2^2), 20 points, seed 44: the first seed from 1
  for which no gap between the points (and the ends) is wider than 0.12 and the fit's error never rises
  by more than 0.03 from one point to the next. The seed is chosen for the picture, a fit that improves
  steadily as the points arrive; the choice is a display decision and is stated here.
  f_n(x) = k(x)^T (K + lambda I)^-1 y, RBF kernel exp(-(a - b)^2 / (2 l^2)), l = 0.14, lambda = 0.04 = (0.2)^2 / 1^2;
  drawn on 101 points of [0, 1]; before the first point the fit is the prior mean, 0.
  CHECK 1: against scikit-learn's KernelRidge, every n: 2.3e-14.
  CHECK 2: against scikit-learn's GaussianProcessRegressor (the same kernel fixed, noise 0.04), its posterior mean: 2.7e-15.
  rms error of the fit against sin(2 pi x): n = 0: 0.704, n = 2: 0.527, n = 5: 0.487, n = 10: 0.230, n = 15: 0.194, n = 20: 0.161

5. OPTIMIZATION: gradient descent on a least squares objective
  A line y = w_1 + w_2 x fitted to 30 points (x uniform on [-3, 5.4], y = 0.8 + 0.5 x + N(0, 0.3^2), seed 1):
  J(w) = |X w - y|^2 / (2 N), a quadratic; its Hessian X^T X / N has eigenvalues 0.7405 and 7.6485 (condition 10.33),
  its shallow axis at -11.2 deg. w_{k+1} = w_k - eta grad J(w_k), eta = 1.6 / lambda_max = 0.2092, 28 steps from
  w_0 = w* - 2.2 v_shallow + 0.5 v_steep = (-1.2836, 1.4281) to (0.75842, 0.51496);
  w* = (0.77781, 0.51113). Distance to w*: k = 0: 2.2561, k = 1: 1.8833, k = 2: 1.5815, k = 4: 1.1240, k = 8: 0.5724, k = 16: 0.1489, k = 28: 0.0198
  CHECK 1: w* (normal equations) against numpy.polyfit: 7.8e-16; the last iterate is 2.0e-02 from it.
  CHECK 2: the rate. The error obeys e_k+1 = (I - eta H) e_k, so it shrinks by max |1 - eta lambda_i| = 0.845099
    per step once the steep mode has died out; measured over the last step: 0.845099 (-1.2e-10).
  CHECK 3: the contours drawn, J = J* + c for c = 1.25 J(w_0) x 0.42^j, j = 0 .. 5, are the ellipses
    w* + V diag(sqrt(2 c / lambda)) (cos f, sin f); J evaluated from the data on 97 points of each: 3.3e-15 (relative).
  The plane is drawn at one scale for w_1 and w_2, so each step meets the contours at right angles
  as drawn.
