MODEL (his page inverse-regularization-animation.html, the same numbers)
  N = 64 cells, x_i = (i + 1/2)/N; G_ij = exp(-(x_i - x_j)^2/(2 s^2)) / (s sqrt(2 pi)) / N, s = 0.045.
  m(x) = exp(-((x - 0.28)/0.07)^2) + 0.75 [0.58 < x < 0.8] at the cells: |m| = 3.672853, max Gm = 0.737936.
  d = Gm + e, e = sigma z, sigma = level max|Gm| = 7.3794e-04, 7.3794e-03, 7.3794e-02 for
  levels 0.1%, 1%, 10%; z standard normal, numpy default_rng seeds (1, 2, 3) (draws 1, 2, 3),
  |z| = 6.8650, 7.7808, 8.5487 (expected sqrt(64) = 8). The noise level of the discrepancy principle is
  delta = sigma sqrt(N) = 8 sigma, the expected |e|, as his pages take it.
  Estimates: m = sum_i f_i (u_i^T d / s_i) v_i with numpy's SVD G = U diag(s) V^T (LAPACK gesdd, float64):
  none f = 1; truncated SVD f_i = [i <= k]; Tikhonov f_i = s_i^2 / (s_i^2 + alpha^2). Residual, norm and error from
  the coefficients: |Gm - d| = |(1 - f) U^T d|, |m| = |f U^T d / s|, error |m - m_true| / |m_true|.

GRID AND PARAMETERS
  The problem is discrete by definition (his 64 cells); there is no mesh to converge. The strength slider spans
  log10(alpha / s_1) = -7 to 1 (his range, alpha = 9.9103e-08 to 9.9103); the L-curve is drawn
  through 321 strengths (40 per decade), the estimate for any strength the reader sets is the page's own sum
  (7. below). Discrepancy alpha: brentq on log10 alpha (xtol 1e-14); best alpha: bounded minimization of the
  true error (xatol 1e-12 in log10 alpha); corner: the maximum of the closed-form curvature, refined from 4001
  strengths. Truncated SVD: every k from 1 to 64.
