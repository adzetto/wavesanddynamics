nf-wt-bridge: the fun table, 'Bridge vibration' (image2)

MODEL
  simply supported Euler-Bernoulli girder, L = 40 m, EI = 3.60e+10 N m^2, m = 12000 kg/m,
  modal damping zeta = 0.015; a two axle truck, 100 kN front and 200 kN rear, 4 m apart, at v = 30.5 m/s (110 km/h),
  one truck every 2.5 s. Closed form modal response, 8 modes, the steady state summing
  the 40 crossings before (their residue e^(-zeta w1 40 P) = 1.1e-07).
  speed parameter alpha = v / (2 f1 L) = 0.2242
  the headway is kept off a whole number of first mode periods (P f1 = 4.25): trucks arriving in
  step with the ringing would pump it (at P f1 = 4.08 the steady state peak is 28 % higher).

CHECK 1: natural frequencies, closed form (n pi / L)^2 sqrt(EI/m) against Hermite FE (60 elements)
  f1: closed form   1.7004 Hz, FE   1.7004 Hz, rel. error +4.7e-09
  f2: closed form   6.8017 Hz, FE   6.8017 Hz, rel. error +8.3e-08
  f3: closed form  15.3039 Hz, FE  15.3039 Hz, rel. error +4.2e-07
  f4: closed form  27.2070 Hz, FE  27.2070 Hz, rel. error +1.3e-06

CHECK 2: quasi static limit, a load P at midspan: modal series against P L^3 / (48 EI)
  8 modes: 3.702551e-08 m, closed form 3.703704e-08 m, rel. error -3.1e-04

CHECK 3: one crossing, closed form against direct integration of the modal equations (RK45, rtol 1e-10)
  mode 1: max |closed form - RK45| / max|q| = 5.1e-10
  mode 2: max |closed form - RK45| / max|q| = 1.4e-10
  mode 3: max |closed form - RK45| / max|q| = 4.5e-10

CHECK 4: the same crossing by an independent FE model (60 Hermite elements, the load consistent
  on the element under each axle, Newmark average acceleration, dt = 2e-4 s, the same modal damping)
  midspan deflection, max |FE - modal| / max |w| = 1.3e-04 (max w = 12.253 mm)
  static maximum at midspan 10.968 mm; dynamic amplification 1.117

CHECK 5: the loop closes: steady state at the end of a period against its start
  max |Q(P) - Q(0)| / max |Q| = 3.6e-09
