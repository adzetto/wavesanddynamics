MODEL
  ideal string, fixed ends: L = 0.648 m (guitar scale), tension T = 72.0 N, tuned to E4 f1 = 329.63 Hz,
  so mu = T / (2 L f1)^2 = 0.3945 g/m (a plain steel string of 0.25 mm: 0.3978 g/m);
  wave speed c = sqrt(T/mu) = 427.20 m/s. Mode 2: w = A sin(2 pi x/L) cos(w2 t), f2 = 659.26 Hz.

CHECK 1: natural frequencies, finite differences (T w'' = -mu w^2 w, fixed ends) against n c / 2L
    50 intervals: f1 = 329.5758 Hz (-1.6e-04), f2 = 658.8263 Hz (-6.6e-04), f3 = 987.4267 Hz (-1.5e-03)
   200 intervals: f1 = 329.6266 Hz (-1.0e-05), f2 = 659.2329 Hz (-4.1e-05), f3 = 988.7985 Hz (-9.3e-05)

  second order convergence to f_n = n f1, as the central difference must.

CHECK 2: the standing wave is the sum of two travelling waves (d'Alembert)
  max |sin(kx) cos(wt) - [sin(kx - wt) + sin(kx + wt)]/2| over a period = 5.6e-16
  and each travelling wave moves at w/k = 427.20 m/s = c: the dispersion relation of the string.
